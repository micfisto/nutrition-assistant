О проекте

Nutrition Assistant — персональный помощник по питанию. Расчёт нормы калорий и БЖУ, подбор рецептов, учёт аллергий и составление меню на неделю.

Возможности

  • Калькулятор КБЖУ по формуле Миффлина-Сан Жеора
  • Подбор меню с учётом целей (похудение, поддержание, набор массы)
  • Фильтрация рецептов по аллергенам
  • Меню на 7 дней с динамическим пересчётом калорийности
  • Регистрация и личный кабинет (JWT-аутентификация)

Стек технологий

  • Frontend: HTML5, CSS3, Vanilla JS, Vite
  • Backend: Node.js 20, Express 5
  • База данных: PostgreSQL / Supabase через Prisma (есть In-Memory режим)
  • Авторизация: JWT + bcryptjs
