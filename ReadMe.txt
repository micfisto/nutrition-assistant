О ПРОЕКТЕ
	Название: Nutrition Assistant
	Описание: Веб-приложение с интеллектуальным помощником для расчёта суточной калорийности и формирования персонального плана питания.

ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
	1. Пользователь может указать основные данные:
		возраст;
		пол;
		рост;
		вес;
		уровень физической активности;
		цель питания.

	2. Система рассчитывает рекомендуемую суточную калорийность на основе введённых данных.

	3. Система позволяет учитывать пищевые предпочтения и ограничения пользователя.

	4. Система формирует персональный план питания на выбранный период.

	5. Пользователь может просматривать блюда и рецепты, включая:
		название блюда;
		список ингредиентов;
		количество ингредиентов;
		способ приготовления;
		калорийность и пищевую ценность.

	6. Пользователь может заменять отдельные блюда или ингредиенты в сформированном плане питания.

	7. Пользователь может взаимодействовать с помощником в текстовом формате для уточнения параметров и изменения сформированного плана питания.
	
	8. Система предоставляет рекомендации по составлению рациона с учётом заданных пользователем параметров.
	
	9. Система хранит данные, необходимые для работы приложения:
		данные пользователей;
		рецепты;
		продукты и ингредиенты;
		сформированные планы питания;
		пользовательские настройки и предпочтения.
